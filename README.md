# GitHub Actions Practice Repository

This repository contains hands-on practice exercises for learning GitHub Actions and CI/CD concepts used in modern DevOps workflows.

The practice set covers:

* Workflow creation
* Push and manual triggers
* Jobs and steps
* Environment variables
* Conditional execution
* Matrix strategy
* Artifacts
* Secrets management
* Docker workflows
* Reusable workflows
* CI/CD pipeline design

## Learning Objectives

By completing these exercises, you will learn how to:

* Automate software workflows using GitHub Actions
* Build and test applications automatically
* Configure branch-based deployments
* Use self-hosted and GitHub-hosted runners
* Store and manage secrets securely
* Create reusable workflows for enterprise CI/CD
* Integrate Docker into pipelines
* Debug and troubleshoot workflow failures
